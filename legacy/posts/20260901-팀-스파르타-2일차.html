클래스와 객체

클래스

같이 다녀야 하는 값을 하나의 모양으로 묶기 위해 사용한다

ex)빵틀, 설계도

객체

클래스라는 설계도를 바탕으로 만들어진 완성품

생성자

객체를 만들때 필요한 값을 빠뜨리지 않도록 입력을 강제하고 정의 하는 방법

접근 제어자와 캡슐화

접근 제어자

public: 모든 곳에서 접근 가능

protected: 같은 패키지 및 상속 관계의 클래스에서 접근 가능

default (키워드 없음): 같은 패키지 내부에서만 접근 가능

private: 같은 클래스 내부에서만 접근 가능

캡슐화

객체의 데이터(필드)를 private으로 숨겨 보호하고, 검증된 기능(메서드)만 외부에 안전하게 공개하는 것 .

Getter, Setter

Getter와 Setter: private 필드의 값을 외부에서 안전하게 조회(Getter)하거나 변경(Setter)할 수 있도록 제공하는 메서드 .

기본 타입과 참조 타입

기본 타입(Primitive Type): boolean, int, double 등 실제 데이터 값을 직접 변수에 저장하는 타입

속성이나 기능을 가질 수 없다.

참조 타입(Reference Type): 객체를 담는 변수이며, 데이터가 저장된 실제 메모리 주소(Heap 영역 주소)를 가리킨다.

참조 타입 간의 비교 시 단순 값 비교와 객체 주소 비교를 유의해야 한다

래퍼 클래스(Wrapper Class): 기본 자료형을 객체로 감싸서 편리한 데이터 처리를 위한 기능들을 제공하도록 돕는 클래스

사용 이유 : 기본 자료형과 관련된 메서드를 사용할 수 있다.

자료구조

배열 : 동일한 타입의 값 여러 개를 한 번에 담는 도구이나, 한 번 정한 크기는 바꿀 수 없다.

시간 복잡도 : 데이터를 찾아오는 속도, 0(n)이 클수록 느리다 ex) for(int i =1; i<n;i++) 0(n)

주요 자료구조:

List: 순서대로 값을 쌓아두는 목록으로, 동적으로 크기가 늘어난다. 0(n)

Map: 키(Key)와 값(Value)의 쌍으로 값을 식별하여 저장하고 꺼내는 저장소 0(1)

Set: 순서를 보장하지 않으며 중복된 값을 알아서 걸러주는 모음 구조 0(1)

Static

static : 정적, 메모리 주소값이 고정되어 있다.

프로그램이 시작될때 메모리에 미리 올라가기 때문에 객채를 생성하지 않고도 바로 사용 할 수있다.

객체를 만들어서 변경을 시도하면 객체에 있는 내용이 변경되는 것이 아니라 클래스에 있는 내용이 변하기 때문에 사용에 주의해야 함.

ex) bread b1 = new bread();

bread b2 = new bread();

b1.name = "소보로빵"; b2.name = "피자빵";

System.out.println(b1.name); System.out.println(b2.name);

의 출력값이 둘다 피자빵이 된다.

상속

상속(Inheritance): 기존 부모 클래스의 필드와 메서드를 물려받아 새로운 자식 클래스를 만드는 문법

자식 클래스는 super 키워드를 사용해 부모 클래스의 생성자를 호출하여 초기화

오버로딩(Overloading): 같은 이름의 메서드를 매개변수의 타입이나 개수만 다르게 하여 여러 개 정의하는 것

오버라이딩(Overriding): 상속 관계에서 부모의 메서드를 자식 클래스에 맞춰 다시 재정의하는 것

@Override 어노테이션으로 컴파일러에 재정의 의도를 전달할 수 있다.

어노테이션: 클래스,메서드,필드등의 코드의 부가 정도를 표시하는 문법

@기호로 시작하며, 컴파일러나 프레임 워크가 코드를 검사하거나 특별한 방식으로 처리할때 사용

추상 클래스와 인터페이스

인터페이스(Interface): 구현 세부 정보를 숨긴 채 "어떻게 만들어야 한다"는 약속/규격(명세)만 정의하여 통일된 소통 구조를 만듬

추상 클래스(Abstract Class): 자식 클래스들이 공유할 공통 코드를 담고 반드시 채워야 할 메서드를 정의하는 클래스로, new 키워드로 직접 객체를 생성하는 것이 불가능

다형성(Polymorphism): 동일한 메서드 호출이더라도 실제 어떤 객체(구현체)이냐에 따라 서로 다르게 동작하는 성질을 뜻함

final: 변수(상수화), 메서드(오버라이딩 불가), 클래스(상속 불가) 등에 불변 속성을 부여하는 키워드
