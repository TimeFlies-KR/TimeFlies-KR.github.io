3 Layer

하나의 클래스로 모든 API를 처리하면 코드가 복잡해지고 유지보수의 비용이 증가하기에 서버에서의 처리과정을 Controller <--> Service <--> Repository 3개의 계층으로 분리하여 코드 가독성과 유지보수를 쉽게 처리하게 끔 처리

Controller : 클라이언트의 요청을 받고 로직처리를 Service로 넘김, Service에서 처리된 결과를 클라이언트에게 전달

Service : 사용자의 요구사항을 처리하는 실세 중의 실세 DB 관련 처리는 Repository에게 요청

Repository : DB 관리 및 CRUD 작업 처
